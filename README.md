## KASA Tron Task Input Specification

Provide the following inputs when working with `kasa.sol`:

- **Code or spec**: Solidity contract, JSON ABI, config file, pseudo-code, or a plain-English description of expected behavior.
- **Goal**: What you want to do (for example: deploy it, call it from a backend, subscribe to events, estimate Energy cost, add multi-sig, or offline-sign transactions).
- **Target network**: `Mainnet`, `Shasta`, or `Nile`.
- **Stack**: `TronWeb (JS)`, `Trident (Java)`, `gotron-sdk (Go)`, raw HTTP, or gRPC.
